it is the only place they are written. Restating them here would create two copies under an obligation to agree, which
is the drift this repository refuses everywhere else.

## No trackers, deliberately

`sources` is empty and stays empty. The package's ordinary model is *a task closes, an entry is owed* — but this diary
runs on the owner's cadence, not on closures: he decides when a moment is worth recording, and an entry is never
written unprompted. Configuring a tracker here would manufacture obligations he did not ask for and turn a diary into a
changelog.

So the trigger is `/ustrecap`, by hand. Everything below that — sealing, chaining, the cap, verification before
storing — is the package doing exactly what it does for anyone.
